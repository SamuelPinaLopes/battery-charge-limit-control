traditional approuch for looping through iterators
#include <iostream>
#include <filesystem>
namespace fs = std::filesystem;

int main() {
    fs::path directoryPath = ".";  // Current directory
    
    // STEP 1: Create the iterator
    fs::directory_iterator it(directoryPath);
    // Now 'it' is like a bookmark pointing to the FIRST item in the directory
    
    // STEP 2: Get the first item
    fs::directory_entry entry1 = *it;  // *it gets whatever 'it' is pointing to
    std::cout << entry1.path().filename() << std::endl;
    
    // STEP 3: Move to the second item
    ++it;  // Move the bookmark forward
    fs::directory_entry entry2 = *it;
    std::cout << entry2.path().filename() << std::endl;
    
    // STEP 4: Move to the third item
    ++it;
    fs::directory_entry entry3 = *it;
    std::cout << entry3.path().filename() << std::endl;
    
    return 0;
}

#include <iostream>
#include <vector>
#include <string>

int main() {
    std::vector<std::string> filenames = {"file1.txt", "file2.txt", "image.jpg"};
    
    // Create iterator
    std::vector<std::string>::iterator it = filenames.begin();
    std::vector<std::string>::iterator end = filenames.end();
    
    for (; it != end; ++it) {
        // *it is the string at current position
        std::string currentFile = *it;  // Dereference to get the string
        
        // Now you can use string methods!
        if (currentFile.compare(0, 4, "file") == 0) {
            std::cout << currentFile << " starts with 'file'" << std::endl;
        }
        
        // Or directly without copying:
        if ((*it).length() > 10) {
            std::cout << *it << " is long" << std::endl;
        }
        
        // Or use arrow operator (more common):
        if (it->find(".txt") != std::string::npos) {
            std::cout << it->c_str() << " is a text file" << std::endl;
        }
    }
    
    return 0;
}

what goes inside of a header file?
Header Guards Explained
The #ifndef, #define, #endif pattern prevents the header from being included multiple times: cpp
#ifndef CALCULATOR_H  // If CALCULATOR_H is NOT defined...
#define CALCULATOR_H  // ...then define it

// Your declarations here

#endif  // End of the guard



Alternative (modern): You can use #pragma once instead (simpler, works on most compilers): cpp
#pragma once  // Does the same thing as header guards

// Your declarations here

HOW TO KNOW IF IT WAS HIBERNATING?

The Tell-Tale Message!
You can check for this exact string in the kernel ring buffer using dmesg:

The Solution: Systemd Service with After=hibernate.target
Instead of your program checking every second, you let systemd notify your program when hibernation happens.

How It Works?
You create a small systemd service that is configured to start after the system resumes from hibernation

This service runs a script or program that re-applies your battery threshold

Systemd automatically triggers it at the right moment



Systemd has special targets that activate during power state changes:
|        Target              |          When it activates       |
|____________________________|__________________________________|
|    suspend.target	         |    When entering sleep
|    resume.target	         |    After waking from sleep
|    hibernate.target	     |    When entering hibernation
|    hibernate-resume.target |    After waking from hibernation

HOW TO CREATE A DIRECTORY WITH FILESYSTEM LIBRARY?
return Value (Important)
create_directory returns a bool:

true → Directory was created (didn't exist before)
false → Directory already existed



Create Parent Directories Too
Use create_directories (plural) to create the whole path:

cpp
// This fails if "/tmp/a/b/" doesn't exist
fs::create_directory("/tmp/a/b/c");

// This creates all missing parent directories
fs::create_directories("/tmp/a/b/c");  // ✅ Works


HOW TO CREATE A FILE!
Creating a File
You create files using file streams, not std::filesystem:

cpp
#include <fstream>

std::ofstream out("/tmp/myfile.txt");
out << "data";
out.close();


Why The Difference
std::filesystem = managing the filesystem (create/remove/move directories and files)
std::ofstream = writing data to files


To create an empty file, you can also use:
cpp
std::ofstream("/tmp/myfile.txt").close();

HOW TO USE PYTHON INSIDE C++?

Method 1: system() - Simplest

Method 2: Capture Python Output
cpp
#include <cstdio>
#include <array>
#include <string>

std::array<char, 128> buffer;
std::string result;

FILE* pipe = popen("python3 script.py", "r");
while (fgets(buffer.data(), buffer.size(), pipe) != nullptr) {
    result += buffer.data();
}
pclose(pipe);
