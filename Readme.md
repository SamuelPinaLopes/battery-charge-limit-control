# Battery limit control
I have noted that my Linux laptop (I'm using Arch Linux with KDE plasma by the way), always 
when I restart it or I even shut down my laptop, the last battery limit I left in settings
will be gone when it opens. Because that now I want to create a program that will
automatically set by battery limit right away I start my laptop into Arch.
And also I want to add a few features in the future.
