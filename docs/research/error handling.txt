how do errors travel between functions?

considering you have: int main(), ask_name() function, write_name() function and open_file() function.

if some error happen in open_file(), cpp will search for a catch block, if didn't find it, it will go back to write_name() and search for a catch block again, if didn't find it again, it will go to ask_name() and search for a catch block again and again until it gets to main.

why always use exception variable as reference?
basically that isn't a variable, is a memory address that holds the exception occurred.
if you didn't use as reference (e.g: std::exception e) it will work, but something called "slice" will happen, it's when cpp receives an exception type, and it converts it into the standart cpp exception type, so, if that happens you will lose meaningfull data that exceptions was caring because the standart exception library does not have that exact structure.


syntax:
try {
    // some code here
}
catch (std::exception& e) {
    handler_error(e);
}
